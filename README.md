## Overview

A polished, animation-rich website for a creative studio. Focused on performance, beautiful interactions, and easy content management.

### Key Highlights

- Next.js 16 with App Router and TypeScript
- Sanity CMS for flexible content editing
- Advanced animations with GSAP and Lenis smooth scrolling
- Three.js for 3D elements
- Tailwind CSS 4 + modern styling
- Email integration (Resend / Nodemailer)
- Rate limiting with Upstash
- Sentry for error monitoring
- Playwright & Vitest for testing

## Getting Started

```bash
# Install dependencies
npm install

# Development (runs on port 3001)
npm run dev

# Type checking
npm run typecheck

# Production build
npm run build

# Run tests
npm test
npm run test:e2e
```
